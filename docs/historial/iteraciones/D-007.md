# D-007 · APK 0.3.0 con resultado inmediato (2026-09-30)

## Área
D — Compilación y entrega Android de A-004/B-006.

## Diagnóstico
La APK 0.2.0 bloqueaba la captura hasta alcanzar estabilidad temporal y no
mostraba el ICA ni la acción para cocinar directamente en resultado.

## Cambio
Se incrementaron versión a 0.3.0 y `versionCode` a 3. El script de compilación
produce `refluye-campo-0.3.0-pruebas.apk` y su SHA-256. Se actualizaron tres
manuales Word, la hoja PDF y la guía de instalación.

## Verificación
- `npm run typecheck` y `npm run test:coverage`: 54 pruebas, 22 golden y
  cobertura total de ramas, líneas, funciones y sentencias del motor.
- `:app:assembleRelease`: BUILD SUCCESSFUL; lint vital aprobado. La compilación
  usó el respaldo sin daemon del compilador Kotlin tras errores del daemon.
- APK de 52 005 310 bytes; cuatro ABI: arm64-v8a, armeabi-v7a, x86 y x86_64.
- `apksigner verify --verbose --print-certs`: firma v2 válida, un firmante;
  certificado SHA-256 `fac61745dc0903786fb9ede62a962b399f7348f0bb6f899b8332667591033b9c`,
  igual al de la APK 0.2.0.
- `aapt2 dump badging`: paquete `co.refluye.campo`, versión 0.3.0, código 3,
  mínimo API 24 y objetivo API 36. Permisos Bluetooth Classic/Connect/Scan;
  ubicación precisa solo hasta API 30; sin micrófono ni archivos.
- SHA-256 coincide con el archivo `.sha256`:
  `2111b085c1e8951adde6eb9f22c702794f8dbc85f2b769eb59c02e11275ab9ce`.
- `adb devices -l`: ningún teléfono conectado. Instalación, actualización del
  historial, Bluetooth real, TalkBack y pruebas de campo siguen pendientes.

## Restricciones de seguridad
La primera lectura produce orientación provisional; nunca certifica potabilidad.
El motor conserva vetos, descargo microbiológico y exigencia de desinfección.
La firma es de desarrollo y solo corresponde a pruebas internas. Una nueva
versión con igual paquete y certificado debería instalarse sobre 0.2.0, pero
debe comprobarse en Android físico antes de prometer preservación de datos.

## Cierre del ciclo
Compilación y verificaciones estáticas completas. Sigue el guion del doc 13 en
teléfono con dispositivo, especialmente actualización de datos locales,
captura de primera trama, variación sostenida de sensores y comprensión de
«posible tratamiento» frente a «agua consumible».
