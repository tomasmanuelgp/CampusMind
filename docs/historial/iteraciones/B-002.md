# B-002 · Continuidad y advertencias (2026-09-15)

## Área
B — UI/UX y accesibilidad.

## Diagnóstico
Las preguntas y pasos compartían un contenedor desplazable: avanzar podía dejar
el título nuevo fuera de vista. El historial resumía resultados sin incluir el
descargo microbiológico. La vista web emitía una advertencia por una propiedad SVG.

## Propuesta
Reiniciar el contenedor al cambiar de paso y mantener las respuestas en la sesión
persistida. Mostrar el descargo también encima del historial. Usar el atributo
de accesibilidad compatible para el símbolo decorativo.

## Riesgo y control
Al recrear una pantalla se detiene su lectura de audio, evitando que siga leyendo
el paso anterior. Los datos viven fuera del contenedor y no se borran al recrearlo.

## Verificación
Recorrido manual de la vista web DEMO a 390×844 y 320×740: inicio, conexión DEMO,
espera de estabilidad, captura, tres preguntas, veto por olor, resultado y guía.
El avance queda deshabilitado sin respuesta. Al recargar el paso 2 se recupera
el paso 2. No se ofrecen tratamientos para levantar el veto por olor. TypeScript
aprobado. Se comprobó la desaparición del aviso SVG tras reiniciar el servidor.
Estas pruebas no acreditan Bluetooth, TTS ni TalkBack en un Android físico.
Quedan pendientes fuente del sistema al 130 %, sol directo y manos mojadas.

## Restricciones de seguridad
S4: la UI conserva el veto del motor. S6: descargo visible en resultado, guía e
historial. DEMO está identificado de forma persistente en cada pantalla del flujo.
No se cambiaron las reglas del motor ni se añadieron tratamientos.
