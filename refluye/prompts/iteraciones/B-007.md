# B-007 · Conclusión dinámica desde el inicio (2026-10-02)

Área B: UI/UX. La pantalla mostraba sensores y preguntas pero reservaba la
orientación para después de guardar. Esto obligaba a completar nombre y navegar
para saber qué hacer con el agua.

Se añade una conclusión al inicio y una orientación junto a las respuestas.
Cambian automáticamente con la última lectura reciente, cada observación y el
uso elegido; no necesitan nombre de fuente, guardar ni esperar estabilidad.
Las respuestas ausentes se evalúan como «No sé», nunca como favorables.

Se reutilizan `evaluar` y `orientarUso`; no se modifica el motor 0.3.0 ni sus
umbrales. Los estados son «No consumir todavía», «No consumir; busca otra
fuente» y «Posible tratamiento antes de consumir». El último depende de datos,
calibración vigente y observaciones completas; siempre incluye desinfección para
beber, cocinar o utensilios. Los usos no evaluados siguen sin autorización.
Sin datos actuales se retira la posibilidad de tratamiento; las señales de
riesgo observadas continúan vetando el uso aun sin conexión. S1–S8 conservadas.
La tarjeta incluye el descargo microbiológico y distingue DEMO.

Verificación: 69 pruebas aprobadas, TypeScript correcto, motor con cobertura
100 %. Nuevos casos cubren respuestas pendientes, primera lectura, olor sin
conexión, aspecto verde/aceitoso, corrección de respuestas, cambio de datos,
calibración y selección de uso. En web DEMO se comprobó el paso de respuestas
favorables a olor extraño y la aparición/retiro de pasos de tratamiento sin
nombre de fuente ni guardar.

App 0.3.2, versionCode 5. La recepción Bluetooth y la interfaz nativa quedan
pendientes de aceptación con el teléfono del usuario.
