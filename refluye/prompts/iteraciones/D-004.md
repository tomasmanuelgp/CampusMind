# D-004 · APK instalable y empaquetado (2026-09-15)

## Área
D — Compilación, entrega y tamaño.

## Diagnóstico
La aplicación aún no tenía APK. La primera compilación falló por MAX_PATH en
Ninja/Windows. Actualizar Ninja no bastó: había cabeceras en rutas largas de Gradle.
Tras compilar desde una unidad corta temporal, la APK universal pesaba 105.59 MiB,
por encima del objetivo de 80 MB del doc 07.

## Propuesta
Compilar desde un alias temporal al mismo proyecto, con Ninja 1.13.2 y memoria
suficiente para Gradle. Comprimir bibliotecas nativas mediante el plugin Expo,
manteniendo las cuatro arquitecturas. Generar archivo instalable, hash y registro
de verificación. Añadir un script reproducible que restaura el entorno al terminar.

## Riesgo y control
La compresión añade extracción durante instalación. No cambia reglas ni sensores.
Se verifican firma, identificador, versiones SDK, arquitecturas y permisos finales.
El artefacto tiene firma de desarrollo y es para pruebas internas, no publicación.
No se cambió el registro de Windows ni se movieron los archivos del proyecto.
