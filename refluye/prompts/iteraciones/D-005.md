# D-005 · APK 0.2.0 con flujo integrado (2026-09-26)

## Área
D — Compilación y entrega Android de A-003/B-004.

## Diagnóstico
La APK 0.1.0 no incluía la selección de uso ni las observaciones en la misma
pantalla. Había que empaquetar la nueva interfaz para probarla en el teléfono.
La primera compilación 0.2.0 encontró rutas mezcladas entre la unidad corta
temporal y la ruta real del repositorio en Expo autolinking; codegen de Gesture
Handler no podía calcular una ruta relativa entre unidades.

## Cambio
El script `mobile/scripts/compilar-apk.ps1` genera primero el manifiesto de
autolinking con Gradle y normaliza sus rutas a la unidad corta antes de compilar.
La unidad es temporal; el script la libera y restaura variables de entorno.
Genera la APK y un archivo SHA-256. Se incrementaron versión a 0.2.0 y
`versionCode` a 2.

## Verificación
- `npm run typecheck` y `npm run test:coverage`: 49 pruebas; 21 casos golden;
  motor con 100 % de cobertura de ramas, líneas, funciones y sentencias.
- `:app:assembleRelease`: BUILD SUCCESSFUL; lint vital aprobado.
- APK: 52 001 450 bytes (52.00 MB decimales), cuatro ABI: arm64-v8a,
  armeabi-v7a, x86 y x86_64.
- `apksigner verify --verbose --print-certs`: firma válida, un firmante;
  certificado SHA-256 `fac61745dc0903786fb9ede62a962b399f7348f0bb6f899b8332667591033b9c`,
  idéntico al de la APK 0.1.0.
- `aapt2 dump badging`: paquete `co.refluye.campo`, versión 0.2.0, código 2,
  mínimo API 24, objetivo API 36. Permisos Bluetooth Classic/Connect/Scan;
  ubicación precisa solo hasta API 30; sin permiso de micrófono ni archivos.
- SHA-256 de la APK, igual al archivo `.sha256`:
  `5e7bb29e40282b3234344928271abe975a70a2b467f69214306741aba567beb2`.
- `adb devices -l`: no había teléfono conectado. Instalación, migración de
  SQLite, Bluetooth real, TalkBack y pruebas de campo siguen pendientes.

## Restricciones de seguridad
La selección de uso presenta los límites del motor; no convierte una lectura
favorable en autorización de potabilidad, baño, ganadería o riego. El resultado
mantiene el descargo microbiológico. La misma identidad de paquete y certificado
permite una actualización sobre 0.1.0 en principio, pero falta comprobarla en
Android físico. La firma es de desarrollo, para pruebas internas.

## Cierre del ciclo

ciclo debe ejecutar el guion del doc 13 en un teléfono y con el dispositivo;
especialmente comprobar actualización de datos locales, permisos, reconexión,
